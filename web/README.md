# 資治通鑑知識庫 · 網頁

純靜態網站，不需後端。讀取 `web/data/`（由 `data/` 產生），可用本機 HTTP 服務瀏覽。

## 頁面

| 頁面 | 檔案 | 內容 |
|---|---|---|
| 卷目錄 | `index.html` | 294 卷依朝代段落分組（周紀、秦紀、漢紀…），顯示卷名、事件數、論斷數、節數 |
| 卷閱讀 | `juan.html?n=卷號` | 依節（帝號）與年號閱讀；事件編號可點（即本事件的連結）；校勘注、「臣光曰」可展開；可全部展開/收合 |
| 搜尋 | `search.html?q=關鍵字` | 全文搜尋事件與論斷，多詞須同時出現在同一則；結果顯示卷、節、年號並可跳轉；可限定只搜事件或只搜論斷 |
| 時間線 | `timeline.html` | 依年號標題中的西元年排列（前為公元前）；輸入年份跳到該年或之後最近的一條；可依朝代篩選 |

## 如何在本機開啟

瀏覽器直接開啟 `index.html`（file://）無法讀取資料，請用本機 HTTP 服務：

```powershell
cd web
python -m http.server 8000
```

然後在瀏覽器開啟 <http://localhost:8000/>。

## 重新產生網站資料

網站資料是 `data/` 的精簡複本，改動 `data/` 後需重新執行：

```powershell
python web\build.py
```

`build.py` 只讀取 `data/`、不修改 `data/`、`raw/`、`scripts/`，產出寫入 `web/data/`：

- `juanNNN.json`：每卷完整內容（壓縮格式，內容與 `data/` 相同）
- `meta.json`：卷目錄、朝代分組、時間線索引
- `entities/`：若 `data/entities/` 存在則一併複製（見下節）

## 人物/地名連結（預留）

`assets/common.js` 的 `KB.loadEntities()` 會嘗試讀取 `data/entities/index.json`。檔案不存在時回傳 `null`，網頁照常運作；`juan.js` 內已留下接收點，日後可把人名連到對應條目。目前尚未實作連結。

## 驗證方式

以下為建立時的實際檢查（Chrome 內建瀏覽器，本機 `http.server`）：

1. **首頁**：載入後顯示 294 卷、16 段朝代、31,430 個事件、141 則論斷。
2. **卷頁抽查**：第 1、2、6、65、111、294 卷皆能載入，節與年號、事件編號、論斷正常顯示。
   - 第 2 卷「展開全部注記」後共 48 個注記展開，「收合全部注記」後皆收合。
3. **搜尋**：`諸葛亮` 得 64 則結果（事件）；點第一筆結果後跳到 `juan.html?n=65&s=2#ev-2-11`，目標事件存在並被高亮。
   - 論斷搜尋：`天子 禮`（只搜論斷）得 9 則，結果可跳轉。
4. **時間線**：
   - 輸入 `前403` 跳到 `前402 年`（威烈王二十四年，該年或之後最近的一條）。
   - 輸入 `956` 跳到 `956 年`（後周太祖）。
   - 朝代篩選「唐紀」得 68 條。

重新驗證的步驟：啟動上面的 `http.server`，依序開啟上述頁面與網址即可。

## 已知問題與限制

- **資料殘留**：部分事件文字中仍有 wikitext 殘留，例如 `1__TOC__`（卷 111 等）、`3----`（卷 6）。這是 `data/` 解析層的問題，本次未修改 `data/`，需回到解析器處理。
- **無法解析西元年**：有 10 條年號標題無法取得西元年，未列入時間線（時間線頁面底部會顯示數目）。
- **時間線年份**：只取年號標題括號內的西元年，未使用各事件自身的年份。
- **論斷搜尋**：索引已去掉「臣光曰：」前綴，因此搜「臣光曰」不會有結果。
- **首次搜尋較慢**：搜尋頁需先讀取全部卷檔（約 13 MB），之後同一頁面內搜尋即時完成。
- **朝代分組**：依卷名中的「○○紀」推斷，無卷名者沿用前一卷；卷 67 等卷名缺漏者即是如此。
- **GitHub Pages**：Pages 只能從儲存庫根目錄或 `/docs` 發布，若要公開需另行調整（例如改成 `docs/`）。
