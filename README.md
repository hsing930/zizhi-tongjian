# 資治通鑑知識庫（zizhi-tongjian）

以《資治通鑑》全書 294 卷為對象，建立可檢索、可追溯的結構化知識庫。方法參考 [shiji-kb](https://github.com/baojie/shiji-kb)（《史記》知識庫）：先把古文變成結構化資料，再從資料產生索引與網頁。

| 階段 | 內容 | 狀態 |
|---|---|---|
| 1. 取得原文 | 從維基文庫抓取 `資治通鑑/卷001`–`卷294` 的 wikitext | 進行中 |
| 2. 結構化解析 | 拆分卷、年號、編號事件、「臣光曰」論斷、校勘注 | 解析器已通過卷 001 測試 |
| 3. 實體與事件抽取 | 人物、地名、官職、年代 | 未開始 |
| 4. 網頁成品 | 全文瀏覽、檢索、時間線 | 未開始 |

## 目錄結構

```
raw/        維基文庫原始 wikitext（juanNNN.wiki），來源未經修改
data/       解析後的結構化 JSON（juanNNN.json）與 _index.json 總表
scripts/    fetch_wikisource.py（抓取）、parse_wikitext.py（解析）
整理日誌.md  每次執行的紀錄
```

## 重新產生資料

```powershell
python scripts\fetch_wikisource.py   # 抓取（已存在的檔案會跳過，可續抓）
python scripts\parse_wikitext.py     # 解析為 data/*.json
```

抓取約每秒 0.5 次請求，遇到限流會退避重試。

## 實體抽取方法與已知限制

執行：`python scripts/extract_entities.py`（讀取 `data/juanNNN.json`，輸出 `data/entities/`）。

- **方法**：不使用外部 NLP 或 LLM，採詞典加規則。官職與地名各以內建詞典（含別稱）比對；人物以百家姓常見姓氏（含複姓）加 1–2 字名，且名字後必須接「曰、為、與、將…」等語境字，並排除首字為「主、人、卿、公…」的稱謂。全書出現 ≥2 次的人名進 `people.json`，只出現 1 次或不確定者進 `_review.json`。地名另有「X州／郡／縣／關／城／山／河」後綴規則，結果一律列為待確認。
- **輸出**：`people.json`（人物）、`places.json`（地名與邦國，如魏、秦、趙）、`offices.json`（官職與稱號）、`_review.json`（待人工確認）、`_summary.json`（各類數量與各卷數量）。每個實體含統一 id、標準名、`aliases`（目前為空）、`first_juan`、`first_year`、`count`、`juans`，以及 `occurrences` 完整出現位置 `{juan, year, event_no}`（`event_no` 為 null 表示「臣光曰」）。
- **已知限制**：
  - **召回率低**：只能抓到「姓＋名＋語境字」的形式。`智伯`、`襄子`、`桓子` 等非百家姓開頭或單獨稱號的人物，以及只出現一次的人名，大多未被自動收錄，需要靠 `_review.json` 或之後補充。
  - **精確率有限**：常見字誤判仍會出現，例如「高麗」、「應州」、「宣徽」、「餘黨散」，地名與官職之間也有混淆。
  - **別稱未合併**：`aliases` 目前為空，「諸葛亮」與「孔明」、「曹操」與「魏武」等不會合併為同一實體，需後續人工或字號表補上。
  - **邦國與政權**：`places.json` 內的魏、秦、趙等，實為邦國或政權，與地名共用一表，未另分類。
  - **年號**：`first_year` 取自最近的年號標題，卷首或無年號段落的記載為 null。
  - **稱號**：「天子」「皇帝」「太后」「太子」等稱謂收入 `offices.json`，屬於稱號而非官職。
- **抽樣檢查（粗估）**：抽樣卷 001、060、150、200、280，共 5 卷，檢視自動收錄的人物共 33 筆（自動門檻為 ≥2 次時）。其中約 28 筆為真人名，精確率粗估約 85%（誤判主要是「高麗」「宣徽」「應州」「餘黨散」等非人名）。召回率以卷 001 為例粗估：「曰」前的人名片段約 12 個，自動或待確認可覆蓋約 7 個，約 60%；其餘卷的召回率未逐一統計。以上僅為人工粗估，非正式評測。
